# Third-party code in this repository

`src/runtime/vendor/` holds files copied from other open-source projects, each with a header that
names the source file, commit and modifications. Full license texts:

| Folder | Project | License |
|---|---|---|
| `src/runtime/vendor/xrblocks/` | Google XR Blocks, https://github.com/google/xrblocks | Apache-2.0 (`xrblocks-LICENSE`) |
| `src/runtime/vendor/iwsdk/` | Meta Immersive Web SDK, https://github.com/facebook/immersive-web-sdk | MIT (`iwsdk-LICENSE`) |
| `src/runtime/vendor/pmndrs-xr/` | pmndrs/xr, https://github.com/pmndrs/xr | MIT (`pmndrs-LICENSE`) |

npm dependencies carry their own licenses in `node_modules`.
